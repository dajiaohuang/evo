# Moss Flora of China descriptions

This regional historical collection imports original English descriptions from
the WFO-hosted Missouri Botanical Garden archive. Description and reference
extensions explicitly declare CC BY 4.0 and Missouri Botanical Garden rights.
Original archive bytes and source fields remain independently retained outside Git.

The archive contains 1,722 description rows, including 48 infraspecific rows.
Species-only intake requires exactly one record across the pinned COL26.8 WFO
crosswalk and accepted status. The candidate selection contains 739 species;
935 species rows have no matching COL record and are not assigned guessed IDs.
References join by WFO ID and source identifier, retaining original row locators.

Markup is converted to plain text using the existing flora converter. No missing
text is reconstructed and no character cap is inferred from this archive. These
passages are not complete global species dossiers or current range assessments.
Identifier links do not establish identical taxonomic concepts across dates.

Full Web uses on-demand shards and collapsed passages. Pages preview excludes
the collection. Web verification does not certify Android or iOS delivery.
