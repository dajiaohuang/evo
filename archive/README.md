# Evo 历史归档

当前定位和上传范围见 [项目规范](../docs/project-scope.md)。

- `root/`：原 README、路线、隐私与贡献说明。
- `docs/`：旧设计、来源报告、审计与迁移记录。
- `scripts/`、`tests/`、`src/`：已退出当前交付的阅读站和摘要实现。
- `public/`：停止公开交付的旧摘要快照。

`manifest.json` 记录原路径、归档路径、原始与归档后的 SHA-256。Markdown 中的链接可能为迁移而调整；科学来源与 JSON 回执的原字节不因改写现行说明而改变。历史记录中的统计与路径按记录时语义阅读。

归档不代表当前在线功能，不授权恢复旧正文发布或运行旧迁移。此目录不进入网站或原生应用产物。旧 GitHub Releases 和 Vercel 部署按用户要求保留。
