# Web exploration lifecycle

This application update preserves canonical scientific files and the dataset version. It changes how the Web client schedules, presents and retains work. Native release work remains separate.

- The timeline animates a local cursor and commits the data clock at most every 120 ms. Pausing commits the final age. Paleogeography loads by checksum-addressed frame identity; same-frame cursor changes do not restart requests. A previous verified frame remains visible during replacement, with its actual frame age. Out-of-coverage targets clear the geometry. No interpolation is added.
- Tree layout depends on topology, collapse state, display mode, language and viewport size. Time and selection restyle existing SVG nodes. Cameras survive layout changes, and roving keyboard focus distinguishes focus from selection.
- React Activity retains visited map, tree and diversity views and the exploration workspace while stopping hidden effects. URL hydration applies external navigation before writing back. Selection and view changes create history entries; cursor movement replaces the current entry. Selection does not change time; the inspector provides an explicit range-location action.
- Search uses the runtime data client. In supported browsers, verified row indexes remain in the Worker and only matching rows cross the thread boundary. The Worker keeps at most 24 indexes with a 24 MiB uncompressed-input budget; that budget is not a measured heap bound. Exact catalogue-name ambiguities keep the existing all-exact-matches behavior. Cancelling a consumer stops its result delivery and subsequent processing, but may leave an already shared/downloaded resource available for reuse.
- Local SQL treats each immutable Lab result array as a snapshot. Repeated queries and Parquet export reuse occurrences; local imported rows update independently. Missing numeric values stay null, including ages. Cancellation or the default 30-second deadline terminates the dedicated engine; it can initialise again. Idle engines release after two minutes. The user_data table and workspace notes are never uploaded.
- The navigation has Explore, Reference and Workspace task spaces; stories, data and methods retain their URLs and secondary navigation. Search is available on the home dashboard. Mobile evidence opens as a bottom panel without requiring users to discover detailed mode first.
- Event/story associations, evidence details and Chinese translations load on demand. Translation text was moved without rewriting it; static publication uses the same moved dictionary. PWA updates require an explicit reload action. SQL and note drafts survive same-tab navigation/reload in session storage; saved notes remain in IndexedDB.

`npm run size:check` writes `dist/data/bundle-task-metrics.json`. It counts transitive application JS/CSS imports once for startup, first map, evidence and SQL, with approximately 25% headroom over the measured refactor baseline. Runtime scientific resources, optional translations and external SQL WASM are excluded explicitly. These asset sizes are not LCP, INP, memory or speedup measurements.

Regression coverage includes uninterrupted frame advancement, stale map completions, stable tree DOM/camera/focus, SQL reuse/failure/timeout/cancel behavior, worker ranking and ambiguity preservation, cross-browser URL history and view retention, and mobile search/evidence access. Run `npm run verify:web` for the Web release contract.
