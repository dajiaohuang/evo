# Evo 当前定位与目录

本文件与 `config/site.json` 是当前产品和交付入口。历史方案、旧审计和旧阅读站说明归入 `archive/`，不再作为当前实现或发布承诺。

## 产品

Evo Atlas 是以古地图和物种树为入口的双语探索应用，正式入口为 <https://evo-lovat.vercel.app/evo/>。地图保留时间、投影和选择上下文；类群节点打开 Wikipedia 原文链接，并可查询有可靠分类映射和同版重建坐标的化石证据。名称匹配候选不等于确认分类身份，采样记录不等于分布全集或起源。

GitHub Pages 只介绍应用并提供 Vercel 入口，不发布应用副本、科学分片、节点正文、专题或独立阅读站。旧节点、专题和导读正文已停止公开交付。Wikipedia 只提供链接，不下载、展示或重新发布摘要正文。实现细节见 [Wikipedia 链接](wikipedia-col.md) 与 [节点地图](node-map-query.md)。

节点正文、资料与来源历史保留。本地新稿通过 [Turso 创作接口](local-turso-authoring.md) 保存；本地保存不等于公开发布。节点标准仍适用于已有或未来获准制作的内容，不表示这些页面当前在线。原生移动工程保留，不能把 Web 测试或网页入口当成新移动版本已交付。

## 目录职责

| 目录 | 用途 | 交付范围 |
| --- | --- | --- |
| `src/`, `public/`, `config/` | 应用、公共资源、站点入口配置 | 仅构建所需资源和经过核验的公开产物 |
| `pages/` | GitHub Pages 介绍页模板和样式 | 独立输出到 `dist-pages/` |
| `scripts/`, `database/`, `backend/` | 构建、数据工具、本地创作和可选查询服务 | 源码随 Git；数据库、凭据和本地回执不上传 |
| `data/`, `content/` | 冻结科学输入、来源绑定、历史规范文件和构建依赖 | Git 中现有输入保留；不直接上传到 Pages 或 Vercel 源码包 |
| `docs/` | 当前维护、产品、来源与交付规范 | Git 文档；不是网站正文 |
| `android/`, `ios/` | 原生工程与平台适配 | 独立、手动准备和验证 |
| `archive/` | 旧设计、审计、历史阅读站工具与测试 | 保留追溯；禁止进入网站产物 |
| `.git/` 与忽略目录 | 本地数据库、来源工作区、构建输出、私有回执 | 不上传 |

文件归档先检查调用和来源绑定，记录原路径、目标路径与 SHA-256。仍被构建、校验或来源引用的数据属于保留依赖，不能仅因页面入口关闭就判为多余。科学 ID、源字节和版本哈希不因目录整理而改写。

## 上传边界

1. **Git 主分支**：源码、规范、冻结输入与有追溯清单的文档归档。只暂存本次文件；不包含并行修改、凭据、数据库、生成目录、缓存或本地研究产物。
2. **GitHub Pages**：`pages:build` 和 `pages:check` 生成、校验的 `dist-pages/`；体积上限 256 KiB。工作流不执行科学数据构建。
3. **Vercel**：`.vercelignore` 白名单中的配置、产物描述及解包脚本；应用来自按大小和 SHA-256 固定的 Release 产物，不从整库上传。当前基包与 overlay 都是部署依赖。
4. **Wikipedia 数据分支**：只发布链接分片和 manifest；保持原子更新和内容哈希。不得把正在使用的分片当旧数据撤下。
5. **远端撤下**：本轮仅调整 Git 当前文件和网站发布范围。用户明确选择保留旧 GitHub Release 资源与旧 Vercel 部署；它们不在本轮删除范围内。

## 验证

`rtk npm run verify:pages` 检查介绍页的实际文件、链接、语言、手机布局和旧路径提示。`rtk npm run typecheck` 检查应用类型；应用交互、Wikipedia 与节点地图改动分别运行对应测试。历史阅读站测试仅保留追溯，不再充当 Pages 验收。
