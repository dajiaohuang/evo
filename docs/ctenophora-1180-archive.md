# WoRMS Ctenophora archive projection (1180)

This source-specific projection freezes ChecklistBank dataset 1180, “Phylum
Ctenophora: list of all valid species names. Electronic internet document”,
version 2026-09-01, version DOI `10.48580/d3fq.v88`. The metadata records CC
BY (`cc by`) and the source URL `http://faculty.washington.edu/cemills/Ctenolist.html`.
The committed official `/archive` bytes are 136,436 with SHA-256
`63feaa32a25368a8a5eae966d224f0345c1d120b6e777c0eb19353fdebc965a9`.

The COL boundary is the exact accepted-species closure below root usage
`B8V3L` (Ctenophora) for source dataset 1180. It contains 197 COL species;
the archive contains 201 species-ranked accepted source rows. Exact NFC and
whitespace-normalized scientific-name plus authorship matching produced 197
accepted records and 4 source-only records. No fuzzy, case-folded,
accent-folded, synonym, or species-concept matching is used. Source-only is
relative only to this COL source-1180 boundary and is not a claim of globally
new species.

The committed ZIP preserves complete original Name, Taxon, NameReference and
Reference rows. Projection shards retain selected source name/author/ID
fields, complete citation objects, and source row locators. The COL partition
contains 197 records and the independent upstream-only partition contains 4;
the largest uncompressed shard is 504,367 bytes. Web delivery is
summary-only; native-full carries all 201 projected records.

The importer is offline and reproducible with the committed archive and
metadata. Its focused test performs two temporary output-root rebuilds,
compares every canonical shard, descriptor and ledger byte-for-byte, and
checks every projected source ID, name/authorship, raw archive row,
references, and locators. This is a nomenclatural/source crosswalk, not a
species-concept equivalence, biological dossier, fossil assessment, or expert
review.
