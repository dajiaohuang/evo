# 节点内容与展示制作标准 v1

本规范用于制作每个节点的页面、列表卡片、地图气泡、短浮窗、阅读窗和局部树入口。人工作文、批量制作与组件实现都遵循同一标准。既有页面按此迁移；规范建立不代表全站已经迁移完成。

制作时使用[节点制作模板](templates/node-presentation.md)。[阅读设计说明](reader-content-design.md)保留全站入口与既定交互，[内容存储说明](content-storage.md)规定实际写入位置。本文件是节点制作要求的唯一依据，不另建重复的规范或维护台账。

## 1. 每个节点共用一套内容骨架

**身份 → 阅读问题 → 核心内容 → 交互展开 → 关联内容 → 来源。**

这是同一节点的信息层次，不是要求所有页面使用六个相同的标题。正文标题必须指向实际生物、结构、发现或问题。

| 层次 | 制作要求 | 展示位置 |
| --- | --- | --- |
| 身份 | 保留稳定标识、真实名称、节点类型与适用的分类位置；属、种、类群、标本、事件不能混称 | 所有形态都能辨认对象；长编号放材料或来源中 |
| 阅读问题 | 一个具体问题，以及说明对象为何值得读的一句科学导语 | 卡片、短浮窗和阅读窗开头 |
| 核心内容 | 按节点类型组织真实内容；观察、解释及适用范围相互对应 | 阅读窗正文；短形态仅取其中有来源的核心事实 |
| 交互展开 | 指定交互对象、动作及动作后读者能看到的材料 | 正文相关段落旁；操作说明写在控件中 |
| 关联内容 | 指明关联对象、关系依据和继续阅读的理由 | 正文中的相关位置及文末；不是任意推荐列表 |
| 来源 | 每个科学断言可回到支持它的研究、记录或固定版本；保留必要定位与范围 | 断言旁可打开来源；详细书目与技术字段可展开 |

主线面向有基本生物分类常识的读者；物种、属与具体材料详情面向已有一定知识的爱好者。术语在首次影响理解时就地解释，不预设读者懂所有研究方法。

### 内容共用规则

- 一个节点只有一套身份、科学事实与来源绑定。不同展示形态是同一内容的展开层次。
- 卡片导语是正文核心内容的经编辑缩写；短版不能新增正文和来源都没有的断言。不能用机械截断代替摘要。
- 名称、年代、坐标、标本编号、来源和相关对象保持一致。语言切换保留相同对象与阅读位置，不把不确定性翻译成确定结论。
- 节点性质决定内容范围。属节点不写成单个物种；上级类群的特征不自动复制为所有成员的事实；标本的观察不自动推广到整个物种。
- 不展示专家评审状态、审阅记录、评审摘要、鲜度评分或维护进度。科学争议与材料局限用正文解释，来源版本与日期留在科学来源信息中。

## 2. 每种展示形态的固定要求

下列长度是中文编辑目标，不是必须填满的配额。英文按相同信息量独立写作。学名、正式地层名和必要限定不因字数被截断。

| 展示形态 | 固定内容 | 默认密度 | 主动作 |
| --- | --- | --- | --- |
| 树节点与地图标记 | 可辨认的名称或符号；选中后显示对象身份 | 不放段落；拥挤时聚合或按需展开 | 选中并打开短浮窗；键盘也可操作 |
| 悬停提示 | 名称、对象类型、一个必要识别信息 | 1–2 行；不承担唯一入口或唯一科学解释 | 点击、触摸或键盘可取得相同信息 |
| 列表与推荐卡片 | 名称或科学标题、一句导语、至多两项有意义的上下文；有合适素材时附图 | 标题通常不超过 24 字；导语约 35–70 字 | 打开该节点的短浮窗或已有阅读窗 |
| 地图气泡 | 对象、地点或材料身份，以及与当前场景有关的科学导语 | 约 60–120 字，至多两个短段；年代和地点与正文分开排 | 展开阅读窗；地图保留 |
| 短浮窗 | 身份、阅读问题、至多三条核心事实、相关材料或图注 | 一屏可理解对象与阅读理由；不是一屏资料表 | 继续阅读；比较、来源是次级动作 |
| 阅读窗与完整页面 | 科学导语、分类型正文、相关材料、局部树、关联阅读、来源 | 首屏导语约 80–160 字；正文每段通常 100–220 字、2–4 句 | 阅读与操作正文中的材料；可收起或返回 |
| 材料与来源卡片 | 实际材料或书目身份、说明它支持什么、原始入口；图片还保留图注和权利信息 | 只呈现与当前段落有关的材料 | 查看原材料或来源，再回到同一段落 |

每张卡片只有一个主要阅读动作。数量、编号和覆盖率只有在帮助读者理解当前结果时才显示；资源包代码、内部断言类型和构建清单不占阅读首屏。

### 标题、导语与段落

1. 标题使用对象名称、具体结构、发现或问题。副标题说明科学内容，不写“探索某某”“点击进入”“查看证据”等导航说明。
2. 导语直接给读者一个可理解的起点：对象是什么，哪项结构、生活现象或发现值得继续读。
3. 一段推进一个意思。先描述材料或现象，再解释联系；不把段落写成编号、指标和免责声明的拼接。
4. 用具体小标题推进正文，例如“仍有鳍条的胸鳍”“牙齿记录了哪些差异”，不把所有节点统一成“概述／特征／意义”。
5. 结论涉及的地点、年代、样本或分析范围写在它旁边。重要争议放相关正文，不全部埋入末尾折叠栏。

## 3. 不同节点类型的固定正文顺序

类型由实际对象决定，不能只根据页面所在目录或是否在树上出现判断。表中的模块是阅读顺序；没有材料的可选模块不渲染空壳。

### 生物与材料节点

| 节点类型 | 正文顺序 | 应有的主要交互 |
| --- | --- | --- |
| 物种与属 | 身体结构 → 生活方式与栖地 → 演化关系 → 具体研究案例；名称和简短分类身份放页首 | 检视结构或标本；可展开局部树；有可比材料时比较近缘对象 |
| 高级类群与支系 | 认识代表成员 → 对应结构的异同 → 分支关系 → 随时间变化的材料 → 研究问题 | 分支选择与形态比较可切换；比较同一结构，并说明材料缺失 |
| 化石记录、标本与收藏集合 | 记录了什么 → 保存的具体材料 → 年代与发现地点 → 据此可讨论什么 → 原记录与研究 | 选材料、查看有权展示的图像、定位对应记录；不将集合编号冒充单件标本编号 |
| 性状或结构 | 结构在哪里、是什么 → 实际对象中的观察 → 对应关系与差异 → 功能解释或演化讨论 | 标注结构、对照同一部位；观察、同源判断与功能推断分别说明 |

局部树选择改变局部材料与高亮，不替换当前文章。不能仅因两种材料外形相似，就自动建立同源关系或比较结论。

### 时间、地点与叙事节点

| 节点类型 | 正文顺序 | 应有的主要交互 |
| --- | --- | --- |
| 演化事件 | 发生了什么变化 → 有来源的阶段 → 涉及的生物与地点 → 如何解释 → 仍有分歧的问题 | 分阶段时间线逐步展开；阶段绑定自己的材料、年代和来源 |
| 地点 | 在这里发现了什么 → 相关生物与材料 → 有证据的环境背景 → 对应地层 → 研究解释 | 化石发现视图与地层剖面视图切换；仅链接有记录对应关系的材料与层位 |
| 地层或组 | 正式单位与位置 → 岩石、层序和年代范围 → 已记录材料 → 相关地点 → 研究 | 选择层位与材料；未有来源的厚度、连续层序和环境变化不能画成实测剖面 |
| 地质时间单位 | 时间范围与边界 → 有来源的环境或生物背景 → 相关地点、材料与章节 | 选择时间区间、进入相关内容；年代边界不自动等于某类群起源 |
| 故事与主线章节 | 一个问题 → 连续的观察或研究案例 → 科学解释 → 关联阅读 | 连续阅读与章节地图联动；章节只绑定它实际涉及的场景 |

一个事件没有阶段材料时，展示已有的变化与研究内容；不能为满足时间线外观补造“早期／中期／晚期”。

### 名录与支持节点

| 节点类型 | 正文顺序 | 应有的主要交互 |
| --- | --- | --- |
| 只有名称资料的节点 | 接受名与异名 → 固定来源的分类位置 → 已有来源 → 真实相关内容 | 浏览来源分类、打开已有文章；保持为可读的名称资料卡 |
| 导航分组、历史级群与未解析位置 | 对象名称 → 这个分组表示什么 → 实际包含哪些内容 → 来源或命名边界 | 浏览已记录成员；明确导航分组与科学分类的区别，不补造祖先 |
| 系统发育假说节点 | 假说中的位置 → 对应样本与拓扑 → 使用的方法或校准 → 竞争解释与来源 | 查看相应假说中的局部树；内部节点没有依据时不制作祖先生物画像 |
| 参考文献 | 书目身份 → 在当前内容中支持什么 → 有实际阅读依据的研究说明 → 原文定位 | 从引用打开，再返回原段落；只有书目元数据时不生成研究摘要 |
| 图片、视频与模型素材 | 素材本身 → 所示对象和具体图注 → 关联内容 → 作者、来源与权利 | 放大或操作素材；区分标本照片、复原图与解释性示意图 |
| 数据集与发布版本 | 来源与对象范围 → 实际提供的材料 → 使用方法与科学局限 → 下载与版本 | 实际下载、查看来源与版本差异；不以记录数量推算生物多样性 |
| 科学解释、来源与关于 | 读者的问题 → 具体说明或演示 → 对应材料与来源 | 合并阅读窗内切换“科学解释／来源与下载／关于” |

目录、搜索、比较、筛选和导出是同一看板中的入口或工具，不单独复制节点正文。SQL、自带数据导入和查询笔记留在折叠的高级工具中。

## 4. 素材与缺失内容怎么处理

- 插图必须有对应对象、图注、来源和使用权依据。没有合适图像时采用文字与已记录结构，不用装饰图冒充标本。
- 复原与示意材料说明哪些部分来自观察、哪些是解释；AI 生成图不能作为标本、行为或科学关系的证据。
- 有身份和分类来源但缺少生物正文时，采用名称资料卡。不能重复父级介绍、拼接百科套话或生成不存在的生态与演化历史。
- 有局部材料时只展开已有部分。会影响理解的缺失要说明，例如“这一材料未保存对应部位”；不为每个空字段堆积“未知”。
- 中文和英文按已有材料分别呈现；未写的语言保留原语言材料及明确说明，不能伪装成已完成翻译。

## 5. 地图与时间联动规则

地图是全站入口与持续保留的阅读背景。默认精选地点和生物故事；读者可切到全部可用化石记录。精选内容的选择不代表完整分布。

| 内容提供的定位信息 | 固定行为 |
| --- | --- |
| 有来源绑定的年代与可靠地点或化石坐标 | 从搜索或场景气泡打开时，同步年代、视中心与材料选择；提供返回之前地图的方式 |
| 只有可靠年代，没有可靠地点 | 允许联动时间；保留视中心；不根据名称或宽泛地区生成一个地点 |
| 只有地点，没有与其绑定的可靠年代 | 明确现代或其他已记录坐标语义；保留时间；不能假称为当前古地理地点 |
| 两者均缺失，或地点与年代并非同一材料 | 保留地图场景；只打开实际内容 |

定位必须同时说明：对象或记录、地点或集合标识、时间值与区间、坐标类型、来源；古坐标还保留重建模型。一个对象有多处记录时，定位具名记录或有来源的分布范围，不能把任意一个点称为整个物种的位置。

科学叙事中的年代、数据库记录的年代区间及地图所用重建帧可以不同；分别保留它们的依据。区间中点只是显示选择，最近地图帧也不是新的地质定年。现代坐标和古坐标不混用，不宣称不同模型已经精确配准。

章节跟随地图时，读者手动拖动或改时间即暂停跟随；“回到当前章节”恢复该章场景。关闭来源、比较或材料窗后，返回同一章节和滚动位置。

地图拖动和触摸移动期间必须持续显示画面，不能等待松手才渲染。定位后目标应可见；数据尚未到达时说明正在加载，不能显示错误地点或伪造地图帧。

## 6. 局部树与完整树的固定规则

1. 大地图角落固定放物种树图标，悬停与键盘聚焦显示“前往物种树”；完整树提供返回古地图的控件。
2. 有真实树位置的节点，在阅读窗、材料浮窗等容器内提供默认收起的局部树板块。叶端默认显示父级与相关同级分支；类群默认显示其局部分支。
3. 局部树与完整树共用渲染和操作：拖动、缩放、选择、折叠、键盘操作，以及数据支持的表示切换。局部树区域可调高度，重新展开保留视中心、选择与折叠状态。
4. “在完整树中定位”进入对应表示，展开目标祖先并将目标置于可见位置。操作不丢失正文阅读位置，返回地图保留年代与地图视图。
5. 来源分类、策展导航、化石首现和系统发育假说分别标明含义。没有真实映射时不提供假的定位按钮；不能用导航树冒充研究得到的系统发育树。

没有科学映射的名称资料仍可显示已有来源分类；只有大树实际包含该节点时，才提供向大树定位。

## 7. 浮窗、阅读窗与可访问性

- 短浮窗逐步展开为阅读窗，标题、对象与选择保持连续。桌面默认侧置，允许调宽；局部树和材料板块可拉开。手机使用可展开的下方面板，并保留回到地图的清楚入口。
- 阅读正文默认展开；局部树、详细材料、书目与高级工具按需打开。限制结论的重要科学信息不能只放在折叠的来源栏中。
- 切换窗口保留地图视中心、缩放、投影、年代、图层、筛选、所选材料、章节与滚动位置。临时进入比较或来源时，返回的是原内容，不是首页。
- 悬停提示也能通过键盘聚焦获得；打开、关闭和主动作可用键盘与触摸完成。触摸目标至少 44×44 CSS 像素；关闭浮窗后恢复合理焦点。
- 在 390 像素宽的手机视口内，正文和操作不得横向溢出。科学图确需更大范围时在局部容器内平移或缩放，不拖宽整个页面。

## 8. 实际制作与完成条件

按以下五步完成一个节点，不建立新的评审状态系统。

1. **确认对象。** 找到现有稳定标识、节点类型、分类或导航位置；确定它是完整内容、局部材料，还是名称资料。
2. **整理材料。** 明确正文问题、已有科学事实、适用范围、素材权利、来源定位；确定哪些地图和树交互确有数据支持。
3. **先写正文，再写短版。** 按类型完成正文，从相同事实编辑卡片和气泡导语；对应整理中英文。不能先造吸引人的标题再找材料凑结论。
4. **连接真实操作。** 逐个列出动作、目标及返回位置；地图和树都定位真实对象，比较与来源回到原阅读位置。
5. **检查实际结果。** 阅读卡片、气泡和完整正文，操作手机和桌面入口，检查直达链接、语言切换、来源定位及适用发布版本。

一个节点的制作结果必须满足以下五组条件：

| 条件 | 可直接检查的结果 |
| --- | --- |
| 身份与内容一致 | 名称、类型、分类与对应材料一致；短版没有新增或夸大正文结论 |
| 可以阅读 | 首屏说明真实科学内容；正文按类型推进；术语、样本与关键局限在需要时出现 |
| 可以操作与返回 | 所有显示的主动作有真实目标；地图和树的定位可见；返回保留阅读与地图状态 |
| 可以追溯 | 科学断言、年代、地点、插图与比较能回到适合的来源；缺失不被填造 |
| 可以在实际版本使用 | 手机无整页横向溢出；键盘可用；已有静态与交互版本共享正文和来源，数据不足的版本不会显示空入口 |

内容仍写入现有 canonical 文件：`index.yaml` 保留身份与来源分类；`page.zh.md`、`page.en.md` 写读者正文；`evidence.md` 保留来源、定位和关系。保留现有 `evo:text` 标记与注册字段，用 `rtk npm run content:build` 生成投影。手工主线章节仍使用已有 `data/reading-guides.json`。不要直接修改生成的 `data/` 文件，也不要把模板作为新的资料存储。
