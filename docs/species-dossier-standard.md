# COL26.8 物种科学档案准入标准

**状态：** 2026-09-23 起适用于本目标后续新增与重新审核的固定标准。  
**分类基线：** Catalogue of Life COL26.8，ChecklistBank dataset `316115`，2026-08-20。  
**适用范围：** 该版本中 `rank=species` 且 `taxonomicStatus=accepted` 的 2,183,133 个接受种。标准不随后续目录版本自动迁移。

本标准先于按此标准汇总的完整档案数量记录。新增资料可以显示逐步进展，但不能改变完成定义。概述、目录条目、分类交叉表、自动验证通过或单一字段原文均不等同于完整科学档案。

## 每种必备记录

每条档案以 COL ID 为主键，并冻结校验时的接受名、作者、等级、父链及目录版本。来源身份必须按来源自带 ID、明确同物异名关系或经审阅的唯一概念映射核实；同名、模糊匹配、名称字符串相等及上级分类均不足以建立物种级关联。保留原始分类概念、来源接受状态、对应方法和未解决冲突。

以下七个科学主题必须分别记录状态与有定位的主张：

1. **形态与鉴别**：发育阶段、性别、变异或测量适用范围；指标、单位、采样及鉴别限制。
2. **生活史与繁殖**：生命周期阶段、繁殖方式及行为；观察对象、地域、季节或实验条件。
3. **生态与相互作用**：栖地、资源、宿主、捕食者、寄生者或共生关系；具体关系和研究范围。
4. **演化与亲缘**：系统发育位置、性状演化或分歧时间；必须来自相应系统发育或比较研究，保留分析、样本和不确定性。命名树、分类等级和祖先直觉不能代替此项证据。
5. **地理分布**：记录地点或范围、证据日期、地理精度、原生/引入/栽培/逸生等性质及未采样区域。区域调查不能升级为全球分布。
6. **化石记录**：标本或化石分类单元、地点、地层/年代及鉴定根据；现生种没有确认化石记录时，须明确限定检索范围和记录为“未找到证据”，不能把未检索记作不存在。
7. **保育与风险**：评估机构、评估体系、状态、评估日期、地域与种群范围。没有合格评估时记录“未确认评估”，不得沿用来源中无日期/过期结论或由分布、采集风险推断等级。

每个主题使用 `supported`、`partially-supported`、`searched-no-evidence`、`conflicted` 或 `not-assessed` 之一。`supported` 表示该主题中按上列定义适用的核心子项均已被逐项审阅并有证据，或在受记录检索支持下明确为未发现；只列出一两项事实但未完成核心子项清单时用 `partially-supported`，不计完整档案。`searched-no-evidence` 必须附检索日期、数据库/文献范围、检索式或等价可复现路径、纳入/排除规则及检索者；它只表示该次限定检索没有找到合格证据，不表示事实不存在。相互矛盾的证据保持 `conflicted` 并列示各方，不得强行择一。空字段、未导入、下载失败及身份未核实一律是 `not-assessed`，不得计作已覆盖。

## 证据、权利及适用范围

- 每项事实拆成可独立核查的主张，并有段落级定位：原文短引或忠实转述、原文语言、页码/章节/段落/表图/标本号等 locator、来源稳定 ID、URL 或 DOI、出版/数据版本、发布日期及访问/检索日期。
- 若主张尚无经核验的中文译文，保留原语言主张并标记 `translationStatus: untranslated`；界面必须明确显示“尚未核验译文”，不能以通用占位句冒充翻译。未译主张不能计入完整档案。
- 记录每个来源的权利人、原始许可名称与版本/链接、许可适用对象和归属要求。许可未明或不允许再分发的原文不复制进资产；可记录合规书目元数据及权利状态。不能把平台、聚合站或目录许可推及所链接的文章、图片、标本照片或第三方内容。
- 被主张引用的每个来源必须单独记录 `licenseAssessment`；只有 `item-level-verified` 可支持完整档案。聚合档案许可声明标记为 `aggregate-declaration-only`，不替代原出版物/数据项的许可核查；仅用于名称身份的来源标记为 `identity-only`。
- 每项主张明确适用分类概念、个体/种群/亚种、性别与发育阶段、地点、时间、野生/家养/栽培/化石、观察或实验条件。译文与原文并存，注明译者/处理方式；机器翻译不作为来源。
- 保留来源筛选、身份映射、转换脚本及版本、输入和输出摘要、排除项、歧义和覆盖边界。自动来源导入、自动化检查及相互转载的网页不算独立证据或专家评审。

## 完整档案与评审判定

一个接受种只有在七个主题全部达到 `supported`、`searched-no-evidence` 或有完整争议证据的 `conflicted`，且上列身份、出处、许可、范围与复现信息齐全时，才计为**完整档案**。任何 `partially-supported`、`not-assessed`、未解决身份冲突、无定位引文或不明权利的生物学原文都会阻止此判定。`searched-no-evidence` 可令档案状态完整，但必须始终显示为知识缺口，不能显示为已知生物学事实。

**专家评审**独立计量，不是完整档案的替代字段，也不能由自动审计或作者自审授予。只有具名且领域匹配的外部评审者确认其专业范围、利益关系声明、评审日期、对应内容版本摘要、意见及处理记录后，才能标记为外部专家评审。未审、作者维护审核与外部专家评审分别记录。

全物种完成判定须对固定基线中每个接受种逐一具备可审计结果：完整档案数为 2,183,133，未评估档案为 0，身份/来源/权利校验错误为 0；同时单独公布分类覆盖、带来源原文物种数、入门概述物种数、完整档案物种数、七个主题状态分布及专家评审物种数。任何聚合数字均须能回溯到物种 ID 清单和所用数据摘要。不得将接受种总数改为现生野生生物学物种数，也不得把家养、栽培、逸生和化石范围混为一谈。

## 初始基线与执行约束

### 来源字段标注覆盖（预备筛查指标）

部分已导入描述集保留了来源自己的字段类型。构建器仅把下列窄标签映射到一个主题，以便定位可优先审阅的来源原文；该指标只表示“至少有一段被明确标注的原文”，不表示段落级引文完整、身份概念已人工复核、该主题核心子项齐全或档案可计完整。每个物种每个主题最多计一次，多来源重叠不重复计种。

| 来源字段原标签 | 预备主题 | 限定 |
| --- | --- | --- |
| `morphology`, `Morphology` | 形态与鉴别 | 来源必须以该类型标记非空正文 |
| `habit` | 形态与鉴别 | 仅是来源对植物生活型字段的分类，不包含具体形态测量 |
| `habitat`, `Habitat`, `Ecology`, `biology_ecology` | 生态与相互作用 | 不自动表示宿主、捕食、寄生等关系已覆盖 |
| `distribution` | 地理分布 | 不自动表示全球范围、引入状态或采样完整 |

其他字段（包括 `general`、`description`、`biology`、`diagnosis`、`Diagnostic`、`Biology` 及未列出的类型）不由标签推断主题；即使文字似乎相关，也须逐来源审查后再建档。精确 ID 仍仅证明当前导入关联键，不证明来源概念等同于 COL 接受种。该预备指标与逐档案七主题状态分布分开统计。

依据当前 COL26.8 分片索引，分类基线为 2,183,133 个接受种；来源原文关联 80,838 种，有来源双语入门概述 55 种。当前有 6,841 个唯一种级科学档案条目，全部 incomplete，外部评审为 0。档案条目内，形态与生态各有 6,841 种部分支持，生活史 148 种、演化 6 种、分布 152 种、化石 1 种、保育 20 种部分支持；各主题其余档案条目均为 not-assessed。另有 2,176,292 个接受种尚无档案条目。精确 ID 清单及分片摘要见[档案索引](../data/knowledge/catalogue-dossier-shards.json)。这些数量不能将单主题部分证据冒充完整档案，也不能将无档案解释成没有研究。

所有实施须保持 COL26.8 固定身份基线与原始资料许可边界。按本仓库工作约束，不执行全量本地测试，不部署或发行；完整回归交远程 CI。对原始归档只读并保留校验摘要，禁止以清理缓存、改写原始资产或猜测性映射推进覆盖。
