# Gymnodinium source archive

RC115 retains the fixed ChecklistBank dataset `1177`, **The dinoflagellate genus Gymnodinium checklist**, version `0.1` (2017-06-12). The archive is available from the official ChecklistBank endpoint [`/dataset/1177/archive`](https://api.checklistbank.org/dataset/1177/archive), and its source metadata identifies the underlying Gymnodiniales project and Zenodo DOI `10.5281/zenodo.437529`.

The committed source archive is a 19,661-byte gzip-compressed tar (the endpoint labels the download as an application/zip archive), SHA-256 `7bfcccdfd515b7e5024718bb8c407e5521f727b166fe5a191006658715dbd8d7`. It contains the original `AcceptedSpecies.tsv`, `Synonyms.tsv`, `NameReferences.tsv`, `References.tsv`, `Distribution.tsv`, `CommonNames.tsv`, `AcceptedInfraspecificTaxa.tsv` and `SourceDatabase.tsv` members. The source metadata declares CC0/public-domain availability through ChecklistBank; the importer preserves the archive fields and does not import linked third-party material as new evidence.

The scope is the exact COL26.8 source-dataset-1177 genus `Gymnodinium` node `4RTJ` under Dinophyceae, with 259 strict accepted COL species. Exact source scientific-name plus authorship matching produces 258 accepted mappings and one explicit unmatched COL row. `Gymnodinium p-dorhnii` (`CN83B`) is not silently equated with the source spelling `Gymnodinium p.dorhni` (`T284`); that source row is retained in the separate source-only shard. There are no redirect, ambiguous or withheld rows in this import. The resulting crosswalk is 33,949 compressed bytes, and the source-only shard is 671 compressed bytes.

The archive contains 309 `TaxAccRef` name-reference links and 99 bibliography rows. Eighteen linked `ReferenceID` values have no corresponding row in `References.tsv`; those links remain represented with the original ID, `referenceMissing: true`, and a source-row locator. The importer does not fabricate missing reference fields. `AcceptedSpecies.tsv` row locators, all source fields, classification columns, status fields, and source-only records remain available in the native-full projection.

This is a release-scoped nomenclatural/source crosswalk, not a global Gymnodiniales checklist, species-concept equivalence assertion, biological dossier, fossil record, ecology claim, expert review or independent scientific corroboration. The archive's `IsExtinct`, `HasModern` and `HasPreHolocene` fields are preserved as source fields; they are not an Evo Atlas review of extant status. Source-only counts are relative to this exact COL source-1177 scope and must not be added to the global COL species total.
