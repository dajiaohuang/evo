## Gazella muscatensis: accepted name and source boundary {#col-name-record}
Catalogue of Life release COL26.8 (2026-08-20) records *Gazella muscatensis* as an accepted species, with the recorded name authority Brooke, 1874. This node currently contains a classification record but no biological observation. The record therefore does not support a description of the animal’s form, habitat, range, or behavior.
