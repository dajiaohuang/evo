## Accepted name and placement {#s-4c2374ae1a}
COL26.8 lists Arthroleptis xenochirus Boulenger, 1905 as a species under Anura (order) → Arthroleptidae (family) → Arthroleptis (genus). This is the placement recorded in the release dated 20 August 2026. It identifies the catalogue entry; it does not establish equivalence with a historical dataset concept.

## From the catalogue record to a source row {#s-6d84a98f61}
Start with the COL26.8 classification, then open AmphiBIO v1 row Anf0158. That row follows a Frost 2011 source concept, which has not been reconciled with the current catalogue concept. Read its ecology and reproductive values as entries in that historical compilation.

## What the AmphiBIO row records {#s-cb66ba6d74}
AmphiBIO v1 marks terrestrial as a broad foraging category (Ter = 1) and reports a maximum adult body length of 24 mm. For anurans, the compilation defines body length as snout–vent length (SVL), measured from snout to vent. The row gives both the minimum and maximum offspring-or-egg count per clutch as 9, and the maximum reproductive output as one event per year. It also carries the source code Dir = 1 for direct development; that code does not describe parental care, breeding location or seasonal timing.

These are literature-compiled values, not typical measurements of every individual. The row does not specify sex, population, date or wild versus captive conditions for each reproductive value. A later TetrapodTraits v2.0.1 notice reports corrections to some microhabitat entries inherited from earlier compilations. This row has not been checked against that revision, so its terrestrial flag remains a historical, unverified value; no replacement is inferred.
