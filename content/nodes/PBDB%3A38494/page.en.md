## How the database organizes this group {#s-0c3b4eed44}
PBDB records Pterodactylus at rank genus. This guide follows the database path and links to occurrence pages for 5 species. Parent paths help organize these records, but the number of entries does not measure evolutionary importance, and the PBDB classification is not a complete phylogenetic hypothesis.

## Scope of the occurrence guide {#s-627a0ab77f}
This page groups selected PBDB occurrence guides under Pterodactylus. It is not a complete descendant catalogue or a shared ecological account. Counts refer to occurrence and collection records, not fossil individuals, populations, or sampling intensity. An outer age bracket is a database bound, not a measured origin or extinction date. The PBDB path is one database arrangement and should be kept separate from COL concepts and other phylogenetic hypotheses.
