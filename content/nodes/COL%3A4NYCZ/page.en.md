## Pseudohydromys musseri: accepted name and source boundary {#col-name-record}
Catalogue of Life release COL26.8 (2026-08-20) records *Pseudohydromys musseri* as an accepted species, with the recorded name authority (Flannery, 1989). This node currently contains a classification record but no biological observation. The record therefore does not support a description of the animal’s form, habitat, range, or behavior.
