## Three anthers in the source description {#s-f2cdc2cf0d}
The Brazilian Flora 2020 description records two-lobed leaves with a heart-shaped base and smooth upper surface; the underside is nearly smooth or has fine, appressed hairs. It describes three anthers, an urn-shaped floral base and a spathe-like calyx. The fruit is a legume that opens elastically. Some leaf and flower details are listed as alternatives in the source record.
