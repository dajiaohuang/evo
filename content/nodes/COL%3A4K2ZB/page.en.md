The EltonTraits 1.0 record for *Plecotus balensis* contains the foraging stratum, activity flags. The foraging-stratum field assigns the scansorial category (compiler confidence code A). This is a category assignment, not a share of time or proof of exclusive use. Activity flags mark night activity (confidence code ABC); the flags are not proportions of a daily time budget. Source comments and compiler confidence remain attached to the foraging category. The entry assigns foraging stratum S, a scansorial (climbing) category. Code A records the compilers’ confidence in the source and assignment. The metadata attributes mammalian stratum assignments to Nowak (1999). This is a category, not a share of time among strata or a claim that the species forages only there.

## Activity periods can occur together {#s-e3c8f80d8f}
The archive marks nocturnal feeding activity as 1. Other activity flags can also be 1 at the same time; the values are not shares of the day and do not define a schedule for every date, season, or site. The ABC certainty can involve evidence from a congener; genus- or family-typical activity values are not used to fill species-level gaps.

## Trace each field group to its source labels {#s-61db786a95}
The source labels are metadata:Nowak1999 for foraging stratum and Ref_1 for activity. These fields can draw on different material; a matching reference number in bird and mammal tables does not by itself identify the same source. The archive retains each original string with its file, row, field group, and reference table. The books and papers have not been read individually, so a source label is not a new observation.

## How to read the source fields {#s-569352163e}
EltonTraits fields summarize selected literature-derived categories; unselected or withheld groups remain unspecified, and missing values are not zeros.
