## 这条蝌蚪记录采用什么来源名称？ {#s-54e73d62e5}
这条记录展示 TadpoleTraits 如何归档 Mantella laevigata 的蝌蚪。第 4 版按数据集作者所录分类依据 Amphibian Species of the World 6.2 (2024)，将记录归在 Mantella laevigata、Mantella、Mantellidae 下。文献表：第 3349，3350，5457 行的 Species 与 Species (ASTW) 字段均为 Mantella laevigata。图像测量表没有数据行。该数据集到 COL26.8 的概念映射标为“尚未解决”，因此这些行名并不能确定当前物种身份。

## 数据行实际记录了什么？ {#s-7047d9df41}
TadpoleTraits 第 4 版（工作簿日期 2025.4.21）为这一来源记录保留 3 条文献行和 0 条图像测量行。文献表 Stage 字段的值为 31-35（第 3349 行）；36-40（第 3350 行）；24-30（第 5457 行）。Sample size 按行记录（第 3349 行：n=1；第 3350 行：n=1；第 5457 行：n=4）。这些是来源表中的行，不是去重蝌蚪数量。TadpoleTraits 的 readme 未确认绝对尺寸的单位，因此不据此推断身体大小。
