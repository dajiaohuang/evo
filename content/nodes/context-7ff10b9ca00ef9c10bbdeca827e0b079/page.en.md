## Source classification and concept status {#s-790e484b9d}
AmphiBIO v1 row Anf2884 records *Litoria nudidigita* under the source classification Litoria (Hylidae, Anura). The compilation follows *Amphibian Species of the World* (Frost 2011); this source concept has not been reconciled with a current COL26.8 species concept.

## Foraging category (arboreal) {#s-b35dd16a6f}
AmphiBIO records an arboreal category for this row. It is a broad category, not a fine-scale habitat description. A later TetrapodTraits revision reports corrections to some earlier microhabitat entries; this row has not been checked against those changes, so no replacement value is supplied.

The row lists a maximum of 1 reproductive event per year. AmphiBIO gives no clutch-size or offspring-or-egg-size values for this record; these fields are missing, not zero. The row does not give the population, date or wild-versus-captive conditions behind the annual value.
