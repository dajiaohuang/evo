## Smutsia temminckii: accepted name and source boundary {#col-name-record}
Catalogue of Life release COL26.8 (2026-08-20) records *Smutsia temminckii* as an accepted species, with the recorded name authority (Smuts, 1832). This node currently contains a classification record but no biological observation. The record therefore does not support a description of the animal’s form, habitat, range, or behavior.
