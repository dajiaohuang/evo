## What the assessment's codes mean {#s-30c40095d2}
Table 3 assigns a population-trend code of 0, meaning trend information is missing, and a land-protection code of 4, which Table 2 defines as the whole population being within protected areas. These are the authors' category assignments, not new population counts or measured protection fractions. A zero marks missing evidence; it does not mean a stable population or no risk. Threat code 2 combines categories and does not identify one official status. The area-of-occupancy (AOO) and extent-of-occurrence (EOO) scores classify area criteria; they are not independently reconstructed maps. Protected-area coverage also does not show how effective management is.
