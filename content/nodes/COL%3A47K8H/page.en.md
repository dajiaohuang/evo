## Five food categories in the record {#s-8a37d5bf72}

## A scansorial foraging category {#s-baa4c4f5d8}
The stratum code is S, scansorial (climbing), with confidence code A for the source and assignment. Mammalian stratum metadata attributes these assignments collectively to Nowak (1999). S is a category, not a percentage of time or a claim that the animal forages only in that stratum.
