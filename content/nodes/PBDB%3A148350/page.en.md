## How the database organizes this group {#s-22708dd2c1}
PBDB records Lophocratia at rank unranked clade. This guide follows the database path and links to occurrence pages for 33 species. Parent paths help organize these records, but the number of entries does not measure evolutionary importance, and the PBDB classification is not a complete phylogenetic hypothesis.

## Species, collections, and age records {#s-13689a770d}
Example species pages include Germanodactylus cristatus, Germanodactylus rhamphastinus, Gallodactylus canjuersensis, Kepodactylus insperatus, Beipiaopterus chenianus. Across the selected records, the guide lists 44 occurrence records from 36 collections. Named stratum examples include Altmühltal, Solnhofen, Mörnsheim, Morrison. Each occurrence retains its own collection, age bracket, and reference information; these counts describe the database sample, not animal abundance or population size.

## Scope of the occurrence guide {#s-a9ecbbeb03}
This page groups selected PBDB occurrence guides under Lophocratia. It is not a complete descendant catalogue or a shared ecological account. Counts refer to occurrence and collection records, not fossil individuals, populations, or sampling intensity. An outer age bracket is a database bound, not a measured origin or extinction date. The PBDB path is one database arrangement and should be kept separate from COL concepts and other phylogenetic hypotheses.
