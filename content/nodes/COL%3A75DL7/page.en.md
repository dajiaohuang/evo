## Otospermophilus atricapillus: accepted name and source boundary {#col-name-record}
Catalogue of Life release COL26.8 (2026-08-20) records *Otospermophilus atricapillus* as an accepted species, with the recorded name authority (Bryant, 1889). This node currently contains a classification record but no biological observation. The record therefore does not support a description of the animal’s form, habitat, range, or behavior.
