## Tamias (Neotamias) ruficaudus: accepted name and source boundary {#col-name-record}
Catalogue of Life release COL26.8 (2026-08-20) records *Tamias (Neotamias) ruficaudus* as an accepted species, with the recorded name authority (A. H. Howell, 1920). This node currently contains a classification record but no biological observation. The record therefore does not support a description of the animal’s form, habitat, range, or behavior.
