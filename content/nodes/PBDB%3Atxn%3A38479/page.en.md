## Pterodactyloidea: PBDB classification route {#s-87fa19be1a}
PBDB records Pterodactyloidea at the rank of suborder. This guide follows the database path and links to occurrence pages for 184 species. Parent paths help organize these records, but the number of entries does not measure evolutionary importance, and the PBDB classification is not a complete phylogenetic hypothesis. The selected occurrence rows provide a route to member records, not a group-wide account of shared anatomy or ecology.

Each occurrence retains its own collection, age bracket, and reference information; these counts describe the database sample, not animal abundance or population size.

## Limits of the selected Pterodactyloidea records {#s-11e380f77d}
This page groups selected PBDB occurrence guides under Pterodactyloidea. It is not a complete descendant catalogue or a shared ecological account. Counts refer to occurrence and collection records, not fossil individuals, populations, or sampling intensity. An outer age bracket is a database bound, not a measured origin or extinction date. The PBDB path is one database arrangement and should be kept separate from COL concepts and other phylogenetic hypotheses.
