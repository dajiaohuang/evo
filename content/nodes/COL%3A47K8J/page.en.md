## Diet weights, foraging stratum and activity flags in the compilation {#s-872c58fdb7}
The EltonTraits 1.0 record for *Niviventer coninga* contains the diet weights, foraging stratum, activity flags. The selected diet fields give literature-standardized relative weights of invertebrates 20%, fruit 20%, seeds, nuts and spores 20%, other plant material, including fungi 40% (confidence code ABC). The foraging-stratum field assigns the scansorial category (compiler confidence code A). This is a category assignment, not a share of time or proof of exclusive use. Activity flags mark night activity (confidence code ABC); the flags are not proportions of a daily time budget. Diet weights standardize literature descriptions rather than measure food intake; mammalian ABC entries can include inference from a congener. Source comments and compiler confidence remain attached to the foraging category. The historical same-name entry does not establish that every field is a direct observation of the pinned COL26.8 concept for *Niviventer coninga*.

## Weights assigned to food descriptions {#s-ca7cf90412}
EltonTraits assigns 40% to other plant material (including fungi in the source category), 20% to invertebrates, 20% to fruit, and 20% to seeds, nuts and spores. These weights standardize written descriptions; they are not measured shares of food intake. The ABC code combines high, reasonable and partial confidence, and an estimate may use a related species in the same genus judged ecologically similar. The weights therefore are not all direct observations of Niviventer coninga. A zero weight would not prove that a food is never eaten.

## A broad foraging-position category {#s-7ceb357ac4}
The entry assigns the species to S, the scansorial or climbing category. Code A records compiler confidence in the source and assignment. Archive metadata attributes mammalian stratum labels collectively to Nowak (1999). This is a broad category, not a measure of time spent there, and it does not mean the animal uses no other position.

## An activity label, not a daily schedule {#s-edffc61903}
EltonTraits marks nocturnal activity as 1. Several activity fields can be 1 together, so this code is not a share of a 24-hour budget or a schedule guaranteed across days, seasons and sites. Its ABC confidence code can include a related species in the same genus; no genus- or family-level typical value is used to fill this entry.

## Following the EltonTraits source labels {#s-90e2dae899}
The fields carry the labels Ref_1 and metadata:Nowak1999. Diet, position and activity can come from different material, and a Ref number in the bird table does not necessarily identify the same work as that number in the mammal table. Original labels are retained by file, row and field group. The underlying books and papers have not been individually read, so these labels are trace information, not additional observations.

## How to read the source fields {#s-b03223856b}
EltonTraits fields summarize selected literature-derived categories; unselected or withheld groups remain unspecified, and missing values are not zeros.
