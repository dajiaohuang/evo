## 这条蝌蚪记录采用什么来源名称？ {#s-7cc2d95cbe}
这条记录展示 TadpoleTraits 如何归档 Crossodactylus werneri 的蝌蚪。第 4 版按数据集作者所录分类依据 Amphibian Species of the World 6.2 (2024)，将记录归在 Crossodactylus werneri、Crossodactylus、Hylodidae 下。文献表：第 2634，2635，2636 行的 Species 与 Species (ASTW) 字段均为 Crossodactylus werneri。图像测量表没有数据行。该数据集到 COL26.8 的概念映射标为“尚未解决”，因此这些行名并不能确定当前物种身份。

## 数据行实际记录了什么？ {#s-a32a0f7f0c}
TadpoleTraits 第 4 版（工作簿日期 2025.4.21）为这一来源记录保留 3 条文献行和 0 条图像测量行。文献表 Stage 字段的值为 36（第 2634 行）；31（第 2635 行）；34（第 2636 行）。Sample size 按行记录（第 2635 行：n=16；第 2636 行：n=2）；另有 1 个 Sample size 单元格为空，不按零处理。这些是来源表中的行，不是去重蝌蚪数量。TadpoleTraits 的 readme 未确认绝对尺寸的单位，因此不据此推断身体大小。
