# Leontocebus leucogenys

## overview

<!-- evo:text /records/catalogue-profile/sections/0/text/zh -->
COL26.8 接受名为 *Leontocebus leucogenys*。Matauschek 等（2011）以主要来自野外粪便的线粒体序列检验鞍背狨类群，支持 leucogenys 作为独立分类单元；后续不同名录对它的属级组合并不一致。
<!-- /evo:text -->

## fieldStudy

<!-- evo:text /records/catalogue-profile/sections/1/text/zh -->
Göbel 与 Heymann（2018）在秘鲁 Panguana 私人保护地开展首轮系统灵长类调查。该物种在 35.7 公顷观察区中比随机预期更常出现在林隙或林隙边缘；这里的“偏好”仅指该保护地、该样区和该次调查。论文记录的群体大小也来自局地观察，不应作为全种固定参数。
<!-- /evo:text -->

## classification

<!-- evo:text /records/catalogue-profile/sections/2/text/zh -->
本地 MDD v2.5 源记录使用 *Saguinus leucogenys*，并把 Leontocebus 置于亚属层级；该记录与 COL26.8 的 *Leontocebus leucogenys* ID 未精确联接。本页保留固定 COL 身份，不从词尾相同推断跨名录映射。
<!-- /evo:text -->

## catalogue-profile / limitations

<!-- evo:text /records/catalogue-profile/limitations/zh -->
Panguana 是单一地点的生态观察；林隙关联不是对全分布区栖地偏好的估计。COL 与 MDD 的属级处理和 ID 联接分开记录；页面不据此解决分类争议。尚未外审。 尚未经过外部领域专家评审。
