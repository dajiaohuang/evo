# Otolemur garnettii

## overview

<!-- evo:text /records/catalogue-profile/sections/0/text/zh -->
COL26.8 接受 Otolemur garnettii 为种级 ID 75DM9，隶属属级 ID 63HY8；MDD v2.5 提供英文显示名 Garnett's Greater Galago。下列野外研究来自肯尼亚沿海森林，描述局地活动范围与社会组织，不覆盖本种完整分布区。
<!-- /evo:text -->

## socialOrganization

<!-- evo:text /records/catalogue-profile/sections/1/text/zh -->
在两个沿海森林地点开展的标记重捕与无线电跟踪发现，不同年龄的成年雌性活动范围高度重叠，而年龄相近的雌性重叠较少。成年雄性的活动范围更大，并与雌性范围广泛重叠；常驻雄性之间通常较少重叠，两处种群的雄性更替都较频繁。成年个体很少共同睡眠。这些观察仅来自肯尼亚研究种群，不应外推到全部栖地。
<!-- /evo:text -->
