# Cephalopachus

## Choose a reading path by research question

COL26.8 genus ID 3KFW links to the accepted C. bancanus page (SDLD). Read the Bukit Peramun study of the Belitung subspecies for a local habitat account, then compare it with the Sama Jaya thermoregulation study, which tested captured adults and recovered free-ranging temperature records from one male and one female. These sources address different questions and taxonomic scopes. This is a route through selected Cephalopachus evidence, not an exhaustive genus roster or a genus-wide habitat synthesis.
