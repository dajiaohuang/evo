# Pternistis hartlaubi

## 历史属名与物种概念

<!-- evo:text /records/catalogue-profile/sections/0/text/zh -->
固定 COL26.8 以 Pternistis hartlaubi（4PV6R）组织本页。AVONET v7 BirdLife 2020 第 2515 行与 eBird 2021 对应同名，Avibase ID 为 AVIBASE-56FA0FE6；BirdTree 表对应 Francolinus hartlaubi，原匹配类型为 1BL to 1BT。已读 COL 的旧组合 6JLDP 指向本页接受 ID 4PV6R。名称关联支持查回历史行，不证明各年代所有物种边界相同。

## 地面取食、栖地与留居类别

<!-- evo:text /records/catalogue-profile/sections/3/text/zh -->
栖地行记为 Shrubland（灌丛），密度代码 2 指半开放环境，与单位面积鸟数无关。Omnivore 生态位表示利用多类资源、没有单一主导生态位。营养级另记为 Herbivore；生态位与营养级是不同字段，保留源标签，不互相替换。Terrestrial 指主要在地面步行或跳行取食；Migration=1 是留居类别，两者都没有提供每只鸟的路线、飞行能力或全年食物比例。
