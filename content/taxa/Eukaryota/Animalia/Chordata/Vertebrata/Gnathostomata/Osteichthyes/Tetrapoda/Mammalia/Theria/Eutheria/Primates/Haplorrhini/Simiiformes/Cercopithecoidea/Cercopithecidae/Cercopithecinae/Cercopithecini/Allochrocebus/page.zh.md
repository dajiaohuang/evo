# Allochrocebus

## overview

<!-- evo:text /records/catalogue-profile/sections/0/text/zh -->
本阅读路径按 COL26.8 属级 ID S7Y 组织，固定接受种为 lhoesti、preussi 与 solatus。早期研究常用 Cercopithecus 或 Chlorocebus 组合；保留来源中的名字，再以 COL ID 对应本目录条目。
<!-- /evo:text -->

## readingPath

<!-- evo:text /records/catalogue-profile/sections/1/text/zh -->
先读 Tosi 对三种代表样本的性染色体标记比较，了解 lhoesti 与 preussi 在该数据中的聚类及 solatus 的分支位置；再读鲁氏猴在 Kalinzu 的取食观察。接着读普鲁斯猴 Ebo 周边访谈，区分当地生态知识与野外数量调查；最后把日尾猴 1985—1989 年调查与 1999 年后记录汇编并读，观察已知范围如何随新记录改变。
<!-- /evo:text -->

## interpretation

<!-- evo:text /records/catalogue-profile/sections/2/text/zh -->
这些证据回答不同问题：分子标记比较描述取样序列关系，Kalinzu 研究量化局地取食时间，Ebo 访谈记录居民识别与变化感知，加蓬分布论文汇总野外观察和地方信息。它们不是同一时段、同一采样框架，不能拼接成全属共同分布、生态或趋势结论。
<!-- /evo:text -->

## catalogue-profile / limitations

<!-- evo:text /records/catalogue-profile/limitations/zh -->
这是按 COL26.8 固定属级 ID 组织的短阅读路径，不是完整属综述。三种来源来自局地观察、访谈和有限分子标记，时间与采样框架不同；不能据此概括全属生态或当期保育状况。中文显示名保留拉丁属名，尚未经过外部领域专家评审。
