# Galagoides

## overview

<!-- evo:text /records/catalogue-profile/sections/0/text/zh -->
COL26.8 的固定灵长类名录在 Galagoides 下列出 demidoff、kumbirensis 与 thomasi 三个接受种。这里按对应 COL ID 组织入口；属名和成员表是固定版本的导航口径，不裁决更广泛的婴猴分类方案。
<!-- /evo:text -->

## readingPath

<!-- evo:text /records/catalogue-profile/sections/1/text/zh -->
先读 Ambrose 与 Perkin 的比奥科岛 Moca 夜间调查，了解 demidoff 与 thomasi 的地方记录；再对照 Wickings 等的加蓬同域研究和 Masters 与 Couette 的颅齿鉴定分析。最后阅读 Svensson 等对安哥拉小婴猴的原始描述，追踪鸣声、野外调查与博物馆标本如何共同支撑新种诊断。
<!-- /evo:text -->

## interpretation

<!-- evo:text /records/catalogue-profile/sections/2/text/zh -->
阅读时要区分地点记录、博物馆鉴定与完整分布推断。比奥科与加蓬研究处理 demidoff/thomasi 的同域或历史识别问题，安哥拉论文则围绕另一处发现展开；不同样点和方法不能拼成单一连续分布或属级生活史。
<!-- /evo:text -->

## catalogue-profile / limitations

<!-- evo:text /records/catalogue-profile/limitations/zh -->
这是围绕三个 COL26.8 接受种组织的研究阅读路径，不是属级综述或完整物种志。三个种的全分布、生活史、种群趋势与现行保育状态均未由本批来源系统覆盖；中文属名为编辑译名，页面尚未经过外部领域专家评审。
