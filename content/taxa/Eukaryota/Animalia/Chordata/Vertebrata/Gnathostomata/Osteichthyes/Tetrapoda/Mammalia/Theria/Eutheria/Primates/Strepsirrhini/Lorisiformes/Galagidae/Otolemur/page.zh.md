# Otolemur

## overview

<!-- evo:text /records/catalogue-profile/sections/0/text/zh -->
COL26.8 将接受种页面 75DLX 与 75DM9 列于属级 ID 63HY8。可先读 Nash 与 Harcourt 在肯尼亚两处沿海地点对 O. garnettii 开展的无线电跟踪和标记重捕，再对照 Long 等在南非 Lajuma 对 O. crassicaudatus 进行的季节性食物与激素测量。Harcourt 的南非食性研究及肯尼亚基质利用比较可作专题延伸。各研究地点、时段与方法不同；本页不是属级生态综合。
