# Crocodylia

## overview

<!-- evo:text /records/catalogue-profile/sections/0/text/zh -->
2012 年一项比较研究测量了当时认可的 23 种现生鳄类、共 83 只性成熟个体。研究在上颌后部的主要磨牙位点报告的类群代表咬合力，从库氏凯门鳄的 900 N 到湾鳄的 8,983 N。跨种比较中，体质量是咬合力的主要解释变量；系统发育校正后的模型 R² 为 0.87。吻部相对比例只解释体质量标准化后剩余变异的一小部分，因此宽吻本身不能直接当作更大咬力的替代量；恒河鳄是相对咬力偏低的例外。样本与分类口径属于 2012 年研究，COL26.8 现生鳄目接受种分母为 27；未把后来区分的谱系或旧名下未分开的样本强行映射到新种。
