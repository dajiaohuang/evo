# Crocodylia

## 分类范围与咬合力证据

<!-- evo:text /records/catalogue-profile/sections/0/text/zh -->
鳄目 Crocodylia 是 COL26.8（2026 年 8 月 20 日发布）中接受的目级记录 COL 329，位于 Reptilia 之下。其三个科分支合计有 27 个接受种。此固定分类目录没有现生标志；它决定本页的阅读索引，生物学结论则来自各项研究。

2012 年一项比较研究测量了当时认可的 23 种现生鳄类、共 83 只性成熟个体。研究在上颌后部的主要磨牙位点报告的类群代表咬合力，从库氏凯门鳄的 900 N 到湾鳄的 8,983 N。跨种比较中，体质量是咬合力的主要解释变量；系统发育校正后的模型 R² 为 0.87。吻部相对比例只解释体质量标准化后剩余变异的一小部分，因此宽吻本身不能直接当作更大咬力的替代量；恒河鳄是相对咬力偏低的例外。样本与分类口径属于 2012 年研究，固定 COL26.8 鳄目分支有 27 个接受种；未把后来区分的谱系或旧名下未分开的样本强行映射到新种。

## 阅读路径

<!-- evo:text /records/catalogue-profile/sections/1/text/zh -->
先阅读本页的成年鳄类咬合力比较，再把 Caiman latirostris、Crocodylus johnstoni 与 Gavialis gangeticus 放在一起，比较咬合力、牙压和吻部形态。Crocodylus porosus 还提供另一项追踪迁移研究；应把迁移证据与咬合测量分开阅读。

局地野外证据可按 Alligator mississippiensis → Crocodylus niloticus → Mecistops cataphractus → Crocodylus intermedius 阅读。比较结论之前，先看各页的样本、日期、地点与方法。标本及谱系证据可按 Crocodylus suchus → Crocodylus novaeguineae → Crocodylus halli → Mecistops leptorhynchus → Osteolaemus tetraspis → Osteolaemus osborni 阅读；Crocodylus acutus 另提供群体遗传学入口。各页保留自己的研究引文与限制。

下列三个科的名单可定位其余接受种导读。这是分类目录阅读索引，不是祖先序列，也不是证据成熟度排名。2012 年论文的 23 种框架不能把旧名下混合的样本分配给全部 27 条 COL26.8 记录。PBDB 化石概念及产地记录仍属于另一来源名单，即使学名与此索引中的名字相同，也不合并记录。
