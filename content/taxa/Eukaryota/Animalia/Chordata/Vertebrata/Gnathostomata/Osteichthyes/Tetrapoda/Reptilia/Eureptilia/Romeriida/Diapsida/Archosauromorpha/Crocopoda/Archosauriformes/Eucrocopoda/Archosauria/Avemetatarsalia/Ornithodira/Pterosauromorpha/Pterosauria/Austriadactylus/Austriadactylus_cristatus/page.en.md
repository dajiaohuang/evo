# Austriadactylus cristatus


## Which fossil records this name represents

<!-- evo:text /records/catalogue-profile/sections/0/text/en -->
Austriadactylus cristatus is accepted in the fixed PBDB pterosaur working roster, with database parent Austriadactylus. This guide uses 2 eligible species-level occurrence records from 2 collections and 2 reference identifiers. Occurrences, collections and references are different units, not specimen or individual counts.
